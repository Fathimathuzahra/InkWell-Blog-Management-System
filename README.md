# InkWell - Blog Management System

InkWell is a blog management application developed using Django REST Framework, React.js, and MySQL.

## Features

- User registration and login
- JWT authentication
- Create, view, update, and delete blog posts
- View posts created by other users
- Add comments to blog posts
- Edit and delete your own comments
- Ownership-based permissions
- Input validation
- Django administration

## Technologies Used

### Backend
- Python
- Django
- Django REST Framework
- Simple JWT
- MySQL
- PyMySQL

### Frontend
- React.js
- Vite
- Axios
- React Router
- Tiptap Editor
